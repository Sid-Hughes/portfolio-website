# Portfolio Website

Personal portfolio site with projects and blog posts, built with Astro and managed through Keystatic.

See [portfolio-plan.md](portfolio-plan.md) for the full build plan.

## Workflow

- `main` is protected and always deployable. Changes land via pull request only.
- Work happens on short-lived branches (e.g. `phase-1/foundations`), merged into `main` with a squash merge at each milestone.
